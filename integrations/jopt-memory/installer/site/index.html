本机安装

首次使用先准备一个能在本机运行的 AI、Python 3.12+ 和已登录公司的 Google Drive 桌面版。任选一个 AI 执行，安装程序会配置 Codex 和 Claude Code，并复用现有库和上传任务。

这台电脑的系统

在 Codex 打开安装指令
下载安装包
查看 AI 将收到的指令

在 AI 里发送指令

Codex 打开后发送已填好的指令。Claude Code 请在本地会话里粘贴并发送。浏览器询问是否打开应用时，选择打开。

选公司分配给你的目录

先在 Google Drive 桌面版登录公司账号。窗口出现后，按下面的路径定位你的文件夹。

文件资源管理器Google Drive共享云端硬盘 → JOPT公司分配给你的 JOPT Memory 文件夹

目录示意。选择文件夹后核对来源和去向，再确认安装。

检查上传和首次整理

在 Drive 网页确认一份正式笔记能读回。首次整理先预览，再由本人确认写入。已有完整记录时可以跳过。

需要手动配置的客户端

以下步骤适用于能够访问这台电脑的客户端。网页和手机上的纯云端 AI 暂不纳入。

ChatGPT 桌面

在账号设置的个性化指示中追加文字。用本地会话验证它是否看得到 Basic Memory 工具。

Claude 普通对话

打开 設定 → マイ Claude → 指示，追加文字并保留原有设置。用能访问本机的桌面会话验证。
