# 業務ポータル プロトタイプ（案B・サイドバー型）

企画書「業務ポータル導入企画書」の導入イメージを、画面で触って確認するための単一ファイルのプロトタイプです。すべて例示データで、実際のログイン・保存・配信・連携は行われません。

## 開き方

`index.html` をダブルクリックして、ブラウザの全画面で開きます（サーバー不要）。画面幅が狭いときはサイドバーが隠れるので、左上の「☰」で開きます。

## 画面と移動

- サイドバー：＋リンクを登録／Codexと連携／Slack連携、ホーム／すべての資料・ツール／自分の資料／保存済み
- 「セクションから探す」「大会から探す」を開くと子メニューが出て、選ぶと絞り込み済みの一覧へ移動します
- 上部のパンくずから一つ前の階層へ戻れます。検索欄に入力すると一覧へ移動します
- ホーム：統計、タグ、他部署ピックアップ、AIニュース（RSS表示例）
- 一覧：各行の「開く」「ダウンロード」「保存（☆）」、資料名から詳細（用途・分類・リンク先・共有範囲・利用ガイド）
- Ticket管理シート／クリエイティブのタスクボードは「開く」で下位ページ（サンプルの表・看板）へ移動します
- 限定共有のGitHub資料は、詳細から「Slackでアクセスをリクエスト」できます（Slack通知はプレビュー）
- 「＋リンクを登録」：リンクのみ登録（ファイルは保存しません）。一言ベネフィットと利用ガイドはAI下書きのボタンで埋まります（サンプル動作）
