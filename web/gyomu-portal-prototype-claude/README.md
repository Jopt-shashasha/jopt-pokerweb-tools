# 業務ポータル：第2案（サイドバー型）

編集正本は `index.html`。白色の画面、固定サイドバー、PICK UP／ニュースの左右配置を維持しています。

## ページ構成

- ホーム：用途が分かるPICK UP、短いニュース、検索タグ。数字カードはありません。
- 部門：部署 → 業務一覧 → 関連資料・ツール → 詳細。
- 大会：大会 → 開催回 → 関連業務 → 資料。
- 検索・全資料・自分の資料・保存済み：それぞれ独立したURLで表示。
- ブラウザの戻る・進む、深いページの再読み込みに対応。
- ツール本体は外部リンクを想定し、原型内の表・看板・計算機等は実装していません。

## 登録と連携の展示

- リンク登録／HTMLアップロードの入口を用意。実際のファイル送信は行わず、ファイル名だけ確認します。
- 登録先URLはGitHub、Google Drive、公開ページ等を想定。原本をDriveへ移すことは必須にしません。
- 成果物の利用ガイド生成機能はありません。
- Codex：業務の検索・取得・登録と、最新AIニュースをあわせて取得する表示例。
- Slack：GitHubの限定共有資料へのアクセス申請 → 登録者への通知 → 確認・承認後にGitHubへの招待へ進む流れを表示。
- Slack送信、承認、GitHub招待、Google認証は未接続です。
- PICK UPは展示用の固定例です。正式版の自動抽出方式は後で検討します。

## デモデータ

十部署、業務別の資料、架空記事を含みます。用途・所属・開催回の紐付けは画面確認用です。
デモで追加した登録情報と保存済みの選択は、このブラウザタブのsessionStorageに保持します。サーバーへの保存・アップロードは行いません。

## 開く

`index.html`をブラウザで開けます。ローカル確認は `http://127.0.0.1:8766/`。
公開用コピーは `dist/index.html`、Siteの識別設定は `.openai/hosting.json`。修正はルートの`index.html`から行い、公開用コピーを更新します。
