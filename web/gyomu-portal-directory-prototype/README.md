# 業務ポータル・案C（部署一覧型）

部门／大会概览 → 已登记资料列表 → 资料详情。复用案B的25条样例及已有业务关联；不预设完整业务地图。业务关联可选。

## 本地预览

在本目录运行 `python -m http.server 8770 --bind 127.0.0.1 --directory dist`，访问 http://127.0.0.1:8770/ 。

## 范围

- 搜索、按部门／大会／类型／開催回筛选、排序、收藏、个人资料。
- 链接登记／HTML文件名登记；登记与收藏使用独立的 sessionStorage，仅此标签页保留。
- Google登录、Codex搜索／登记／AI新闻、Slack权限申请、GitHub邀请均为UI预览。
- 内置资料外链未接通。用户在当前标签页登记的HTTP(S)链接，经点击确认后可打开。
- HTML只读取文件名；不读取或执行上传HTML，不上传外部，不提供在线工具内部页面。
- 无自动生成利用指南，无新资料Slack通知，无完整业务分类维护要求。
- 新闻均为虚构显示例。PICK UP更换样例，生产自动抽取方式另行讨论。
- 日期显示使用Asia/Tokyo。

源码正本在本目录。未对原案A、案B、AIFACT、JOPT drop源服务做修改。公司代码仓库不自动commit/push。Sites发布使用该站点独立的源码仓库。
